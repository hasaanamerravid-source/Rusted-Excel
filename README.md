# Rusted Excel

A featherweight desktop spreadsheet. Rust drives a small native GUI; all cell
storage and formula evaluation lives in a C++ core with a C ABI, and CSV I/O is
handled by a tiny C helper. No browser engine, no JS runtime, no heavy toolkit.

> Independent project. "Excel" is a Microsoft trademark; the icon here is an
> original, spreadsheet-style mark generated by `tools/make_logo.py` and is not
> affiliated with Microsoft.

## Features

- Calc-style desktop layout: menu bar, toolbar, name box, formula bar,
  scrollable grid with row/column headers, sheet tabs and a status bar
  showing average/sum/count for the selected range.
- Keyboard-first editing: arrows, `Enter`/`F2`/double-click to edit,
  `Delete` to clear, type to start editing, `Tab` to commit and move right.
- Toolbar actions: New/Open/Save, Cut/Copy/Paste, Undo/Redo, Σ (sum of cells
  above), bold/italic and left/center/right alignment.
- Multiple sheets via the tab bar and the `+` button.
- Formulas evaluated by the C++ engine:
  `=A1+B2`, `=SUM(A1:A10)`, `=AVG(B1:B5)`, `=MIN(...)`, `=MAX(...)`,
  `=COUNT(...)`, `=ABS(...)`, `=ROUND(...)`, `=POW(...)`, `=SQRT(...)`,
  `=IF(A1>0,1,0)`, `=UPPER(A1)`, `=LEN(A1)`, `&` concatenation and
  comparisons (`=`, `<>`, `<`, `>`, `<=`, `>=`).
- Circular-reference and bad-reference errors (`#CYCLE!`, `#REF!`, `#DIV/0!`,
  `#NAME?`).
- Open/save CSV with quoted-field support, including escaped quotes.
- Release binary is ~1.3 MB on Linux x86_64 (LTO + `opt-level = "z"` + stripped symbols).

## Build

Requirements:

- Rust (stable)
- a C and a C++ compiler (`cc`, `g++` or `clang`)
- On Linux, X11 development headers (`libx11-dev libxext-dev libxft-dev
  libxinerama-dev libxcursor-dev libgl1-mesa-dev`)

```sh
cargo build --release
./target/release/rusted-excel
```

Run the tests with `cargo test`.

## Layout

```
include/rx_core.h     C ABI shared by the native code and Rust
native/rx_core.cpp    C++ spreadsheet engine + recursive-descent formula parser
native/rx_csv.c       C CSV reader/writer
src/core.rs           safe Rust wrappers over the C ABI
src/main.rs           FLTK desktop UI
assets/logo.png       app icon
tools/make_logo.py    regenerates the icon with Pillow
```
