# Rusted Excel

A featherweight desktop spreadsheet, version 1.0.0. Rust drives a small native
GUI; all cell storage and formula evaluation lives in a C++ core with a C ABI,
and CSV I/O is handled by a tiny C helper. No browser engine, no JS runtime, no
heavyweight toolkit.

> Independent project. "Excel" is a Microsoft trademark; the icon here is an
> original, spreadsheet-style mark generated by `tools/make_logo.py` and is not
> affiliated with Microsoft.

## Features

- Calc-style desktop layout: menu bar, toolbar, name box, formula bar,
  scrollable grid with row/column headers, sheet tabs and a status bar showing
  average/sum/count for the selected range.
- Keyboard-first editing: arrows (with `Shift` to extend), `Enter`/`F2`/
  double-click to edit, `Delete` to clear, type to start editing, `Tab` to
  commit and move, `Ctrl+Home`/`Ctrl+End`, `Ctrl+A`, and Page Up/Down.
- Toolbar and menu actions: New/Open/Save/Save As, Cut/Copy/Paste with system
  clipboard support, Undo/Redo, Σ (sum of cells above), bold/italic and
  left/center/right alignment.
- Up to five sheets with per-sheet selections, rename/delete actions, and full
  undo/redo snapshots that include formulas, styles and sheet structure.
- Window title and status bar show the file name and unsaved-change state;
  quitting, opening or starting a new document asks before discarding changes.
- Formulas evaluated by the C++ engine:
  `=A1+B2`, `=SUM(A1:A10)`, `=AVG(B1:B5)`, `=MIN(...)`, `=MAX(...)`,
  `=COUNT(...)`, `=ABS(...)`, `=ROUND(...)`, `=POW(...)`, `=SQRT(...)`,
  `=IF(A1>0,1,0)`, `=UPPER(A1)`, `=LEN(A1)`, `TRUE`/`FALSE`, `&` concatenation
  and comparisons (`=`, `<>`, `<`, `>`, `<=`, `>=`).
- Error values propagate through formulas (`#CYCLE!`, `#REF!`, `#DIV/0!`,
  `#NAME?`, `#NUM!`) instead of being silently coerced to zero.
- Open/save CSV with RFC-4180-style quoted fields, escaped quotes and CRLF
  support. Files are written atomically through a temporary file.

## Install on Debian/Ubuntu

Download `rusted-excel_1.0.0-1_amd64.deb` and install it:

```sh
sudo apt install ./rusted-excel_1.0.0-1_amd64.deb
```

The package installs the binary, desktop entry, AppStream metadata, man page,
a `text/csv` MIME association, and hicolor icons from 16×16 to 256×256. The
application appears in the desktop menu as **Rusted Excel**.

To remove it:

```sh
sudo apt remove rusted-excel
```

## CSV behaviour

Opening a CSV replaces the contents of the **active sheet only**. Saving writes
the **active sheet only**; other sheets remain available in the session but are
not persisted to CSV. Formulas are saved as the raw text beginning with `=`, so
they are re-evaluated when the file is opened again. Trailing empty rows and
columns are trimmed on save.

## Build from source

Requirements:

- Rust (stable)
- a C and a C++ compiler (`cc`, `g++` or `clang`)
- On Linux, X11 development headers (`libx11-dev libxext-dev libxft-dev
  libxinerama-dev libxcursor-dev libgl1-mesa-dev`)

```sh
cargo build --release
./target/release/rusted-excel
```

Run the test suite with:

```sh
cargo test
```

Build the Debian package locally:

```sh
tools/build_deb.sh
```

The script writes the package to `/home/rha` by default and accepts
`--version`, `--target-dir`, `--out-dir` and `--skip-build`.

## Layout

```
include/rx_core.h     C ABI shared by the native code and Rust
native/rx_core.cpp    C++ spreadsheet engine + recursive-descent formula parser
native/rx_csv.c       C CSV reader/writer
src/core.rs           safe Rust wrappers over the C ABI
src/main.rs           FLTK desktop UI
tests/core.rs         native engine and CSV regressions
assets/logo.png       master app icon
tools/make_logo.py    regenerates master and hicolor icon sizes with Pillow
tools/build_deb.sh    builds the .deb package without sudo
packaging/            desktop, AppStream, man page, copyright, changelog, icons
```
